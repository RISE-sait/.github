# 🏀 RISE SAIT – Revolutionizing Sports Through Software

Welcome to the official GitHub organization for **RISE SAIT**, a multi-platform sports facility management system built by SAIT students. Our mission is to bridge the gap between athletic performance and digital innovation — from real-time game analytics to seamless scheduling, coaching tools, and barbershop bookings.

---

## 🚀 Projects

| Project | Description | Link |
|--------|-------------|------|
| **Admin Dashboard** | Role-based management for staff, programs, memberships, and barbershop services | [Rise-Admin-Shad-Version](https://github.com/RISE-sait/Rise-Admin-Shad-Version) |
| **Mobile App** | Cross-platform app for athletes, coaches, barbers, parents, and instructors (Expo) | *Private* |
| **Public Website** | Marketing and landing site built with ShadCN, Next.js, and Tailwind CSS | [RisePublicWebsite](https://github.com/RISE-sait/RisePublicWebsite) |
| **Backend API** | Go-based backend with SQLC and Docker powering all services and integrations | [api](https://github.com/RISE-sait/api) |

---

## 🧠 Core Features

- 🔐 Firebase Auth + JWT for secure user access
- 📅 Program, session, and event management
- 💈 Barbershop bookings and portfolios
- 📊 AI-driven stat generation from game video uploads
- 💳 Stripe payments for bookings, memberships, and tournaments
- 🧾 Waivers, attendance, team rosters, and CRM integration
- 🧪 CI/CD with GitHub Actions + Google Cloud Run
